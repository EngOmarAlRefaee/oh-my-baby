OH MY BABY — Baby World + Visual Polish Patch

طريقة التركيب:
1) فك الضغط.
2) انسخ المجلدات التالية إلى داخل مجلد website عندك:
   app, database, resources, routes
3) اختار Replace / استبدال الملفات.
4) من PowerShell داخل website شغل:
   php artisan route:clear
   php artisan config:clear
   php artisan cache:clear
   php artisan migrate
5) إذا السيرفر شغال، أعد تشغيله:
   Ctrl + C
   php artisan serve
6) خلي npm run dev شغال بنافذة ثانية.

التعديلات:
- ترتيب قسم عالم الطفل: التزيين أكبر شيء، العربايات بعدها، والهدايا/الألعاب نفس القياس.
- استفتاء واحد فقط تحت قسم عالم الطفل.
- خيارات الاستفتاء صارت إيجابية وعفوية:
  مهتمين بهالقسم 🤍
  كتير مهتمين وناطرينو ✨
- تحسين تصميم مربع إرسال الملاحظة للإدارة.
- وصول الملاحظات إلى صفحة Marketing عند الأدمن.
- تصغير وتنعيم عنوان قسم المكافآت.
- تحسين عام للأزرار والهوفر والخطوط على الديسكتوب.

ملاحظة:
هذا الباتش مخصص للديسكتوب واللمسات العامة. تنسيق الموبايل نخليه بباتش مستقل لاحقاً.
