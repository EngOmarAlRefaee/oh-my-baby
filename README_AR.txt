OH MY BABY — Final touches patch

هذا الملف يجمع التعديل السابق للاستفتاء + التعديلات الجديدة.

التعديلات:
1) الاستفتاء: الضغط على الخيار يسجل التصويت مباشرة، بدون زر تصويت/تحديث.
   تظهر النسب المئوية فقط للزبون، بدون عدد الأصوات.
2) إزالة عبارة "عم نجهزه ليطلع بأحلى شكل" من كروت الأقسام القادمة.
3) إصلاح نافذة تسجيل الدخول لتكون مرتبطة بالشاشة نفسها وليس بسكرول القسم،
   مع سكرول داخلي مرتب وهيدر ثابت داخل النافذة.
4) تغيير أيقونة السلة من شكل الحقيبة إلى عربة تسوق معدنية/سلكية.
5) توضيح إدارة كود الحسم في لوحة التسويق:
   - الكود
   - نسبة الحسم
   - مفعّل/متوقف
   - أول طلب فقط/كل الطلبات
   - ملخص واضح قبل الحفظ
6) توضيح خانة الكوبون للزبون في صفحة إتمام الطلب.

طريقة التركيب:
- فك الضغط.
- انسخ مجلد resources إلى جذر مشروع website.
- اختر Replace/استبدال للملفات الموجودة.
- إذا npm run dev شغال: اعمل Refresh.
- إذا غير شغال: شغل npm run dev ثم Refresh.

لا يوجد migration جديد ولا تعديل على قاعدة البيانات في هذه الحزمة.
