# Owner Workspace UI — v3

تحسين بصري لحركة hover في بطاقات لوحة المالك:

- تخفيض حركة البطاقة من قفزة واضحة إلى ارتفاع خفيف جدًا (4px تقريبًا).
- إزالة دوران الأيقونة والتكبير القوي.
- جعل الانتقال أبطأ وأنعم باستخدام easing ناعم.
- إضافة ظل خفيف تدريجي بدل التغيير المفاجئ.
- الحفاظ على شكل البطاقات: أيقونة + عنوان فقط.
- إضافة لمسة عمق خفيفة وحد داخلي بسيط بدون ازدحام بصري.
- احترام `prefers-reduced-motion` للحركة.

هذا التعديل واجهة فقط ولا يغيّر قاعدة البيانات أو الصلاحيات أو منطق الحسابات.
