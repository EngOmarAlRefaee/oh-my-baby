# Owner Workspace UI — OH MY BABY

## القاعدة البصرية
- الصفحة الرئيسية للـOwner تعرض 12 قسمًا ثابتًا.
- كل بطاقة تعرض **أيقونة + اسم القسم فقط**.
- لا نعرض الوصف والحالة والأرقام داخل البطاقة حتى تبقى الواجهة نظيفة وسريعة القراءة.
- الـhover يعطي رفعًا خفيفًا، تكبيرًا للأيقونة، وتحويلها إلى لون accent بدون مبالغة.
- ترتيب البطاقات حسب أولوية عمل الـOwner، وليس حسب ترتيب تقني داخلي.

## قاعدة الحسابات الأخرى
نفس أسماء الأقسام تُستخدم مع Admin وDelivery والحسابات المتخصصة. الاختلاف ليس في أسماء الواجهة، بل في:
- Visibility: ما الأقسام التي تظهر.
- Actions: ما العمليات المسموحة.
- Scope: ما البيانات التي يستطيع الحساب الوصول إليها.
- Delegation: ما الذي يستطيع تفويضه أو منحه لحساب آخر.

## قاعدة إنهاء/حذف الموظف
الحساب المرتبط بمهمة تشغيلية نشطة لا يُحذف مباشرة. قبل الحذف النهائي يجب إنهاء المهمة أو إعادة إسنادها لحساب آخر، ثم يسمح النظام بالحذف فقط عندما تصبح العلاقات التشغيلية والمالية آمنة للحذف. وإلا يُستخدم الإيقاف بدل الحذف.
