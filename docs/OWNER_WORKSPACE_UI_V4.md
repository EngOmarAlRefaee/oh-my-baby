# Owner Workspace UI v4

- ألغيت أي حركة `translate` أو `scale` عن البطاقة نفسها أثناء hover، لذلك البطاقة تبقى ثابتة تمامًا.
- أعدت الحركة الجميلة داخل البطاقة: underline من المنتصف، glow ناعم، shine خفيف، وتفاعل الأيقونة.
- الحركة موزعة على 500–700ms مع easing ناعم لتفادي الإحساس بالقفز.
- يحترم `prefers-reduced-motion`.
