# تركيب Patch إدارة الحسابات الآمنة

## قبل التركيب
1. احتفظ بنسخة من المشروع الحالي/commit الحالي.
2. خذ نسخة احتياطية من قاعدة البيانات قبل تشغيل migration جديد.

## التركيب
- انسخ محتويات هذا الـZIP فوق مجلد `website` مع Replace.

ثم من PowerShell داخل `website`:

```powershell
php artisan migrate
php artisan optimize:clear
```

إذا `npm run dev` شغال، اعمل Refresh. إذا غير شغال شغّله بالطريقة المعتادة عندك.

## اختبار آلي

```powershell
php artisan test --filter=TeamManagementSecurityTest
```

## اختبار يدوي من Owner
1. افتح `/owner/team`.
2. تحقق أن الحسابات القديمة تظهر.
3. الحساب غير المستخدم يظهر له زر **حذف نهائي آمن**.
4. الحساب المرتبط بطلبات/سجلات لا يظهر له حذف نهائي؛ يظهر سبب الحماية ويُستخدم إيقاف الحساب بدلًا منه.
5. أنشئ Admin تجريبي مؤقت داخل الموقع بصلاحية واحدة على الأقل، ثم عدّل بياناته، أوقفه، أعد تفعيله، ثم احذفه إذا بقي غير مستخدم.
6. لا تحذف أي حساب حقيقي مرتبط بالطلبات أثناء الاختبار.

## ملاحظة مهمة
Migration رقم `2026_09_27_000001_normalize_and_unique_user_phones.php` يضيف unique constraint لأرقام الهاتف بعد normalization. إذا وجد أرقامًا تاريخية تتطابق بعد إزالة المسافات/الشرطات، سيتوقف برسالة واضحة بدل تعديل البيانات بشكل تخميني. عندها لا تحاول تجاوز الخطأ؛ عالج الحسابات المتعارضة أولًا.
